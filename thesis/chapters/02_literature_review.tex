\section{Customer Feedback Mining and Opinion Mining}

Customer feedback analytics aims to transform large volumes of unstructured comments into interpretable signals about what customers discuss and how they feel. Early work on customer review mining already framed this as a structured opinion-mining problem rather than simple document classification. Hu and Liu proposed mining product features and summarising positive and negative opinions around those features \cite{hu2004mining}, while Pang and Lee situated sentiment analysis within the broader problem of opinion-oriented information access \cite{pang2008opinion}. This line of work motivates the broad problem addressed in this dissertation: customer feedback is useful to organisations only when it can be organised into actionable topics, aspects, and sentiment signals.

\section{Aspect-Based Sentiment Analysis}

Document-level sentiment alone is insufficient for many customer-feedback settings. A review may be positive about staff support but negative about a website, or it may praise price while criticising delivery speed. Aspect-Based Sentiment Analysis (ABSA) addresses this limitation by associating sentiment with specific aspects or targets. Shared tasks such as SemEval-2016 Task 5 helped standardise ABSA settings involving aspect categories, aspect terms, and polarity labels across domains \cite{pontiki2016semeval}. More recent surveys describe ABSA as a family of tasks covering aspect extraction, aspect-category detection, and aspect-level sentiment classification \cite{zhang2023survey}. The key idea for this dissertation is that sentiment should be conditioned on what the text is about, not only on the overall document.

Aspect-conditioned sentiment modelling provides a direct foundation for the modelling choices in this project. Tang et al. argue that aspect-level sentiment classification requires models to attend to the context relevant to a given aspect \cite{tang2016deep}. Although their setting differs from document-level, multi-label customer feedback, the principle transfers: a model should not assign one global sentiment to every aspect mentioned in a review. This is important for the current project because early held-out-aspect baselines used a global sentiment approximation, while the strongest current local non-LLM baseline uses a candidate-aspect DistilBERT selector followed by a DistilBERT aspect-conditioned sentiment classifier. The improvement of the stronger aspect-conditioned pipeline over the global-sentiment version supports the ABSA claim that aspect-specific sentiment is methodologically necessary, while also showing that model strength matters.

Generative and instruction-based ABSA also provide a bridge toward later structured-output LLM comparisons. Yan et al. show that several ABSA subtasks can be reformulated in a unified generative framework \cite{yan2021unified}, while Scaria et al. study instruction learning for ABSA \cite{scaria2024instructabsa}. These papers support treating ABSA outputs as structured predictions, but they should not be used to imply that all instruction-following or generative models will outperform smaller supervised baselines in this dissertation's taxonomy-shift setting.

\section{FABSA as a Customer-Feedback ABSA Benchmark}

The empirical anchor for this dissertation is FABSA, a public customer-feedback ABSA dataset introduced by Kontonatsios et al. \cite{kontonatsios2023fabsa}. FABSA contains approximately 10,574 user feedback reviews, 14 anonymised organisations, 10 domains, 12 child aspect categories, 3 sentiment polarities, and 36 aspect-sentiment pair labels. It is therefore suitable for studying customer-feedback classification because it combines several properties that are often isolated in benchmark datasets: it is customer-feedback oriented, multi-domain, multi-organisation, and multi-label.

In the original FABSA setting, the taxonomy is fixed. This dissertation keeps that fixed-taxonomy setting as a baseline but extends the evaluation to held-out organisations and held-out aspects in order to study different forms of generalisation. The held-out-aspect and leave-one-aspect-out protocols are therefore project-level evaluation extensions rather than claims that FABSA itself was originally proposed as a taxonomy-shift benchmark. FABSA also motivates candidate-aspect scoring because a model can be given a review and a target aspect and asked whether the aspect is absent or present with a polarity. This makes candidate-label modelling a natural extension of the dataset rather than an unrelated modelling choice.

\section{Multi-Label Classification and Evaluation}

The multi-label nature of FABSA is central. A single review can have zero, one, or several aspect-sentiment labels depending on the evaluation scope. Multi-label learning literature therefore provides the basis for evaluating the task. Tsoumakas and Katakis define multi-label classification as a setting in which each instance may belong to multiple labels \cite{tsoumakas2007multilabel,tsoumakas2008multilabel}, and Zhang and Zhou review algorithms and evaluation measures for such tasks \cite{zhang2014review}. In this dissertation, pair samples F1 is used as a headline metric because it reflects per-review prediction quality over aspect-sentiment pairs. Pair micro F1 captures aggregate label-decision performance, while pair macro F1 exposes performance on rarer labels. Aspect-only metrics and sentiment accuracy conditional on a correct aspect prediction help separate errors in aspect selection from errors in sentiment assignment.

Metric choice is especially important in leave-one-aspect-out evaluation. In all-row LOAO, many rows do not contain the current held-out aspect and therefore have empty gold labels. A sample-level F1 score does not reward true-negative empty predictions and can hide different false-positive behaviours. This motivates reporting micro F1, precision, recall, false-positive rows, and exact-match style diagnostics alongside samples F1. The purpose is not merely to report more numbers, but to avoid drawing misleading conclusions about new-aspect detection from a metric that behaves differently when many examples have empty gold labels. General analyses of classification performance measures provide useful caution when choosing and interpreting these metrics \cite{sokolova2009systematic}.

\section{Generalisation under Domain and Organisation Shift}

The dissertation also distinguishes organisation or domain shift from taxonomy shift. Domain adaptation work in sentiment analysis has long shown that models trained in one domain can degrade when applied to another, and that collecting labelled data for every target domain is costly \cite{blitzer2007biographies}. Broader surveys of neural domain adaptation in NLP similarly emphasise that distribution shift is a central generalisation problem \cite{ramponi2020neural}. In this project, held-out organisation evaluation tests whether models generalise to unseen organisations while keeping the same FABSA taxonomy. This is important for customer-feedback analytics because different organisations and domains may have different vocabulary, review styles, and customer concerns. Nevertheless, it is not the same problem as taxonomy shift: the output labels remain known during training.

Cross-domain ABSA work provides a closer task-level comparison point. Yu et al. study cross-domain data augmentation with domain-adaptive language modelling for ABSA \cite{yu2023crossdomainabsa}, and Li et al. propose a structure-aware generation model for cross-domain aspect-category sentiment analysis \cite{li2024structureaware}. These papers help motivate cross-domain ABSA as a relevant related area, while this dissertation's held-out organisation protocol should still be described as an evaluation setting rather than a full domain-adaptation method.

\section{Taxonomy Shift and Candidate Labels}

Taxonomy shift is the narrower and more novel axis of this dissertation. Standard supervised classifiers typically assume that the output label set is fixed between training and inference. This assumption is problematic when customer-feedback taxonomies evolve, for example when new product features, support channels, or complaint categories appear. The broader text-classification literature has treated this as an evolving label-set problem, where new classes may appear after the initial training set has been collected \cite{godbole2005evolvinglabelsets}. More recent work on dynamic text classification similarly argues that fixed-label classifiers are poorly matched to applications where the label set changes over time and labels may be added or removed \cite{wohlwend2019dynamictextclassification}. The practical problem studied here is not free-form topic discovery. Instead, it is candidate-label new-aspect generalisation: at inference time, the model is given a set of candidate aspect labels and must select the relevant ones and assign sentiment. This distinction is important because it makes the task evaluable and operationally realistic while avoiding the stronger claim that the model invents arbitrary new topics.

Candidate-label and zero-shot classification literature motivates this formulation. Ding et al. propose open-domain topic classification with user-defined taxonomies and label-aware classification, showing how labels can be treated as semantic inputs rather than fixed classifier indices \cite{ding2023opendomain}. Yin et al. study zero-shot text classification through entailment-style formulations, where label descriptions help connect unseen labels to text \cite{yin2019benchmarking}. Related work on dataless classification, generalised input-label embeddings, and description-based classification similarly supports the idea that label semantics can be used during inference \cite{chang2008semantic,pappas2019gile,chai2020description}. In this dissertation, these ideas are adapted to FABSA's aspect-sentiment setting: the model receives candidate aspect labels and predicts aspect-sentiment pairs from the supplied candidate set.

This framing also clarifies the role of the project's evaluation protocols. The closed-topic split measures conventional fixed-taxonomy performance. The held-out organisation split measures generalisation to unseen organisations under the same taxonomy. The fixed held-out-aspect split measures whether models can use supplied candidate labels for aspects excluded from training supervision. Finally, LOAO rotates each aspect as held out, providing robustness diagnostics and reducing the risk that a single three-aspect split is unusually easy or hard. These protocols turn the dissertation from a single benchmark comparison into a structured study of how performance changes as the evaluation moves from stable taxonomy to organisation shift and then to taxonomy shift.

\section{Structured-Output LLMs as Candidate-Label Classifiers}

Structured-output LLMs form the final part of the literature review because they are a plausible model family for candidate-label classification. Instruction-following models can consume natural-language label lists and generate structured predictions, and generative ABSA work has already shown that ABSA subtasks can be reformulated as sequence generation \cite{yan2021unified,scaria2024instructabsa}. However, this dissertation should not assume that LLMs are automatically superior. Yu et al. compare open, closed, and small language models for text classification and show that smaller supervised models can remain highly competitive across many classification settings \cite{yu2023openclosedsmall}. This supports keeping DistilBERT-style local baselines as serious comparators. For this project, Qwen and Gemini are therefore best understood as structured generative candidate-label classifiers to be compared under the same held-out-aspect protocol.

Because the LLM output is structured, evaluation must include more than F1. Work on guided generation and structured-output restrictions shows that constraining model outputs can improve parseability but may interact with model behaviour and task performance \cite{willard2023guided,tam2024speakfreely}. JSONSchemaBench and related work on prompting-as-programming further motivate explicit evaluation of schema adherence and structured-output failure modes \cite{geng2025jsonschemabench,beurerkellner2023prompting}. For candidate-label ABSA, invalid JSON, hallucinated candidate labels, invalid sentiment values, duplicate labels, or unparsable outputs directly affect usability. Therefore, future Qwen/Gemini experiments should report valid JSON rate, schema-valid rate, parse failures, hallucinated labels, latency, token usage, and cost-related diagnostics alongside predictive metrics. This keeps the LLM comparison connected to the central dissertation problem rather than turning it into an unrelated API benchmark.

\section{Summary}

The literature supports a dissertation centred on structured candidate-label aspect-sentiment classification under taxonomy shift. Customer review mining motivates the need for structured feedback signals; ABSA motivates aspect-specific sentiment; FABSA provides a public multi-label customer-feedback dataset; multi-label learning motivates the metrics; domain adaptation literature motivates held-out organisation evaluation; candidate-label and zero-shot classification motivate unseen-label prediction from supplied labels; and structured-output LLM research motivates Qwen/Gemini as future model families. The key limitation to state throughout is that this dissertation studies selection from supplied candidate labels, not unrestricted topic discovery or production-ready deployment.
